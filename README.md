# \# DockManager

# 

# A lightweight and fully customizable portable dock for Windows.

# 

# \## Overview

# 

# DockManager is a lightweight Windows desktop application designed to provide

# quick access to applications, folders and frequently used resources through

# a customizable desktop dock.

# 

# The application is designed to be portable and easy to configure.

# 

# \## Features

# 

# \- Customizable desktop dock

# \- Portable application

# \- Shortcut management

# \- Group management

# \- Customizable appearance

# \- Built-in color picker

# \- Application settings

# \- Windows startup management

# 

# \## Requirements

# 

# \- Windows 10 or later

# \- .NET 9

# 

# \## Getting Started

# 

# Clone the repository:

# 

# ```bash

# git clone https://github.com/GaetanoDeRoberto/DockManager.git

cd DockManager

Open DockManager.sln with Visual Studio and build the project.
===

# 

# Publishing

# 

# The project includes a publish profile for creating a Windows x64 build.

# 

# The published application can be used as a portable application without a

# traditional installation.

# 

# Project Structure

# Component	Description

# DockWindow	Main dock interface

# GroupWindow	Group management

# SettingsWindow	Application settings

# ColorPickerWindow	Color customization

# IconService	Icon management

# StartupManager	Windows startup management

# Models	Application configuration models
